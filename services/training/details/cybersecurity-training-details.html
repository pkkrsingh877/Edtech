Cybersecurity Training Syllabus

IT Fundamentals–I

Our IT Fundamentals–I course covers a wide range of topics essential to understanding and working in the field of IT, including hardware, operating systems, security, and networking.

Course Outcomes and Topics Covered

  • Understand portable computing devices and peripherals
    • Laptops, tablets, smartphones, and associated accessories (keyboards, mice, printers, external storage devices)
  • Explore basic cybersecurity principles and best practices
  • Understand key security concepts:
    • Password management
    • Malware protection
    • Encryption
    • Multi-factor authentication
  • Gain knowledge of operating system fundamentals
    • Different operating systems (Windows, Linux, macOS)
    • File structures
    • Command-line interfaces
    • System utilities for management and troubleshooting
  • Basics of Blockchain Technology
  • Explore essential networking concepts:
    • TCP/IP, HTTP, FTP, DNS, common ports
    • Networking tools like Wireshark and ping
  • Understand troubleshooting techniques for common IT issues
  • Explore application templates
  • Develop problem-solving skills for diagnosing and fixing hardware, software, and network-related issues
  • Recognize different types of cables and connectors:
    • Ethernet, HDMI, USB cables
    • Internal components like RAM, CPU, power supplies, motherboards

IT Fundamentals–II

IT Fundamentals–II focuses on building skills in system assembly, diagnostics, performance tuning, virtualization, cloud computing, and network security.

Course Outcomes and Topics Covered

  • Assemble components based on customer requirements
  • Implement system diagnostics and performance tuning
  • Understand hardware compatibility, system specifications, and best practices for building desktops and workstations
  • Utilize diagnostic tools to detect hardware and software issues, optimize system performance, and ensure stability
  • Configure PCs, mobile devices, and software
  • Understand virtualization and cloud computing fundamentals
  • Learn about virtual machines (VMs) and cloud-based solutions
  • Study networking basics and security forensics
  • Develop best practices for data backup and disaster recovery
  • Explore network architectures, protocols, and troubleshooting techniques
  • Learn strategies for safeguarding data, including backup methods and redundancy planning

Network Configuration and Management

This section focuses on advanced networking topics, including network topologies, OSI model, network security, troubleshooting, and performance optimization.

Course Outcomes and Topics Covered

  • Explain network topologies, OSI model, and cabling standards
    • Understand different network layouts (star, mesh, bus, etc.)
    • Explore the seven-layer OSI model and structured cabling standards
    • Ensure efficient data transmission with proper cabling standards
  • Configure wireless networks and security settings
    • Set up and secure Wi-Fi networks using encryption standards (WPA3, WPA2)
    • Apply access control measures and interference mitigation strategies
  • Troubleshoot network interfaces, switches, VLANs, and IP addressing
    • Diagnose and resolve connectivity issues
    • Configure managed switches and implement VLAN segmentation
    • Manage IPv4/IPv6 addressing
  • Implement network monitoring and performance optimization
    • Utilize tools like Wireshark and SNMP to monitor traffic
    • Analyze network bottlenecks and optimize performance
  • Analyze dynamic routing, firewalls, DHCP, and DNS
    • Understand and configure dynamic routing protocols like OSPF and BGP
    • Set up firewalls for enhanced network security
    • Configure DHCP for automated IP allocation and troubleshoot DNS issues
  • Understand network redundancy, failover strategies, and disaster recovery
    • Explore redundancy techniques such as link aggregation and high-availability configurations
    • Plan and implement disaster recovery strategies to ensure network resilience

System Administration

The System Administration course provides in-depth knowledge on Linux OS, system monitoring, performance tuning, user management, security, and automation through scripting.

Course Outcomes and Topics Covered

  • Understand Linux OS basics
    • Learn the fundamentals of Linux, including distributions, file systems, shell environments, and essential commands.
  • Implement system monitoring and performance tuning
    • Use tools like top, htop, and iostat to analyze system performance, identify resource bottlenecks, and optimize processes.
  • Manage user groups and configure permissions
    • Create and manage user accounts, assign group memberships, and implement file and directory permissions using chmod, chown, and ACLs.
  • Configure system security and firewall settings
    • Set up security best practices, manage firewalls (iptables, firewalld, UFW), and implement SSH hardening techniques.
  • Learn file management and software management in Linux
    • Master file operations, directory structures, and package management tools like apt, yum, and dnf for installing and updating software.
  • Automate administrative tasks using shell scripting
    • Write and execute Bash scripts to automate repetitive tasks, streamline system maintenance, and enhance efficiency.

Securing Computing Systems

The Securing Computing Systems course covers essential security concepts, cryptographic solutions, authentication mechanisms, and the implementation of risk management strategies to secure digital environments.

Course Outcomes and Topics Covered

  • Compare security concepts and cryptographic solutions
    • Understand fundamental security principles, encryption methods, hashing techniques, and their role in protecting data.
  • Implement authentication and access control mechanisms
    • Configure multi-factor authentication (MFA), role-based access control (RBAC), and identity management solutions to strengthen security.
  • Utilize cryptographic protocols for data security
    • Learn about SSL/TLS, AES, RSA, and other cryptographic protocols used for securing communications and protecting sensitive information.
  • Analyze security threats, vulnerabilities, and risk management strategies
    • Identify common cyber threats, assess vulnerabilities, and develop risk mitigation plans using industry best practices.
  • Explore secure cloud architectures and Zero Trust security models
    • Study cloud security frameworks, identity-based access controls, and the implementation of Zero Trust principles for enhanced security.
  • Apply security monitoring and incident response techniques
    • Use SIEM tools, intrusion detection systems (IDS), and threat intelligence for real-time monitoring and response to security incidents.

Digital Forensics

The Digital Forensics course provides comprehensive training in cybercrime investigation, digital evidence recovery, forensic analysis, and maintaining legal procedures in the field of cybersecurity.

Course Outcomes and Topics Covered

  • Learn fundamentals of cybercrime investigation
    • Understand digital forensics principles, legal considerations, and methodologies used in cybercrime investigations.
  • Analyze malware, logs, and network traffic for forensic evidence
    • Use forensic tools to detect malicious activities, investigate security breaches, and reconstruct attack scenarios.
  • Understand file systems and data acquisition techniques
    • Explore file system structures (FAT, NTFS, EXT), forensic imaging, and data acquisition methods to preserve evidence integrity.
  • Apply forensic techniques for incident response and threat hunting
    • Develop skills to collect, examine, and correlate forensic artifacts to identify security threats and mitigate risks.
  • Recover digital evidence from volatile and non-volatile sources
    • Extract and analyze data from RAM, hard drives, mobile devices, and cloud environments for forensic investigations.
  • Generate forensic reports and maintain chain of custody
    • Document forensic findings professionally, ensuring adherence to legal standards and proper evidence handling procedures.

Penetration Testing

The Penetration Testing course equips students with the skills necessary to identify and exploit vulnerabilities in systems, networks, and web applications, with the goal of improving cybersecurity defenses.

Course Outcomes and Topics Covered

  • Conduct penetration tests, including reconnaissance and exploitation
    • Perform active and passive reconnaissance, exploit vulnerabilities, and simulate real-world attacks to assess security defenses.
  • Perform web application penetration testing
    • Identify and exploit web-based vulnerabilities such as SQL injection, cross-site scripting (XSS), and authentication flaws.
  • Identify vulnerabilities and assess network traffic
    • Use vulnerability scanning tools and network traffic analysis techniques to detect security weaknesses and anomalies.
  • Gain expertise in privilege escalation and post-exploitation techniques
    • Understand methods to escalate privileges, maintain persistence, and exfiltrate data while maintaining stealth.
  • Use various tools and techniques for security testing
    • Master industry-standard tools like Metasploit, Nmap, Burp Suite, and Wireshark for penetration testing and ethical hacking.
  • Create penetration test reports and provide remediation recommendations
    • Document findings, assess risk levels, and suggest security enhancements to strengthen an organization’s defenses.

Web Application Penetration Testing

The Web Application Penetration Testing course focuses on identifying, exploiting, and defending against common web application vulnerabilities to enhance security and protect sensitive data.

Course Outcomes and Topics Covered

  • Understand web application security architecture
    • Learn about web technologies, authentication mechanisms, session management, and secure development practices.
  • Perform SQL injection, cross-site scripting (XSS), and other common web attacks
    • Exploit and defend against injection attacks, broken authentication, and other web-based vulnerabilities.
  • Identify and exploit web vulnerabilities using automated and manual tools
    • Use tools like Burp Suite, OWASP ZAP, and manual techniques to discover security flaws in web applications.
  • Conduct secure code review and remediation strategies
    • Analyze web application source code for security weaknesses and implement fixes to prevent future exploits.
  • Assess and prioritize security risks in web applications
    • Apply risk assessment methodologies such as OWASP Top 10 and CVSS to evaluate and mitigate security threats effectively.
  • Generate penetration test reports and recommend security improvements
    • Document findings, provide risk assessments, and suggest best practices to enhance web application security.

Mobile Application Penetration Testing

The Mobile Application Penetration Testing course focuses on identifying and exploiting security vulnerabilities in mobile applications for both Android and iOS platforms to ensure secure mobile app development.

Course Outcomes and Topics Covered

  • Learn mobile app security for Android and iOS
    • Understand the security architecture, permission models, and attack surfaces of mobile operating systems.
  • Assess API security and backend communications
    • Test mobile APIs for vulnerabilities like improper authentication, data leakage, and insecure API endpoints.
  • Identify vulnerabilities like insecure data storage and communication
    • Detect risks such as unprotected local storage, improper encryption, and weak authentication mechanisms.
  • Bypass mobile app security controls and protections
    • Analyze techniques for bypassing root/jailbreak detection, SSL pinning, and application tampering defenses.
  • Exploit mobile application security flaws
    • Perform security testing on mobile apps using techniques such as reverse engineering, dynamic analysis, and code injection.
  • Generate penetration testing reports and recommend security improvements
    • Document vulnerabilities, assess risk levels, and provide remediation strategies for securing mobile applications.
