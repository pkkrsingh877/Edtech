# ETSEC Incorporate

ETSEC Incorporate is a premier cybersecurity firm dedicated to providing robust and innovative solutions to protect your digital assets and ensure the integrity of your IT infrastructure. This project includes a website with various sections such as Home, About, Courses, and Contact.

## Project Structure

### Home Page

- **index.html**: The main landing page of the website.
- **index.js**: Contains JavaScript code for interactive elements such as the slider and image hover effects.
- **style.css**: Contains the CSS styles for the entire website.

### About Page

- **about.html**: Provides information about ETSEC Incorporate, including its mission and services.

### Courses Page

- **courses.html**: Lists the various courses offered by ETSEC Incorporate, including categories and popular courses.

### Contact Page

- **contact.html**: Provides contact information and a form for users to get in touch with ETSEC Incorporate.

### Media

- **images/**: Contains all the images used in the website, including course images, branding, and other visuals.

## Technologies Used

- HTML
- CSS
- JavaScript
- GSAP (GreenSock Animation Platform)
- Bootstrap
- Remix Icon
- Font Awesome

## Getting Started

To get started with this project, clone the repository and open the `index.html` file in your browser.

```sh
git clone <repository-url>
cd etsec/Home
open index.html
```
